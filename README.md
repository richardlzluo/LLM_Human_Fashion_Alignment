## Root Directory (`Submission Bundle`)

* **`Items Images/`**: A directory containing the item images. 
* **`Python program for t-SNE and boxplot/`**: A directory containing Python scripts, Juypyter notebooks, and data files used for generating t-SNE visualizations and boxplots.
* **`LLM & participants' response.xlsx`**: An Excel spreadsheet containing responses from LLMs and human participants.
* **`self-assessed alignment score.xlsx`**: An Excel spreadsheet containing scores related to participant self-assessed alignment.
* **`alignment_by_participants.png`**: A plot visualizing alignment data grouped by participants.
* **`alignment_by_questions.png`**: A plot visualizing alignment data grouped by questions.
* **`t-SNE.png`**: The output visualization from the t-SNE analysis.

## `Python program for t-SNE and boxplot/` Directory

* **`response.csv`**: A CSV data file, containing response data used in the analysis.
* **`self-assessment.csv`**: A CSV data file, containing participant self-assessed data used in the analysis.
* **`self-assessment.ipynb`**: A Jupyter Notebook file containing Python code for the self-assessment plot.
* **`semantic_embedding.ipynb`**: A Jupyter Notebook file containing Python code related to semantic embedding and t-SNE analysis.
* **`requirements.txt`**: A text file listing the necessary Python packages and their versions required to run the code in this directory.
